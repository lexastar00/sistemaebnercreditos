# Plantillas de Word

Aquí se guardan los machotes oficiales (.docx) que usa el sistema para generar documentos:

- carta_aceptacion_residencia.docx
- carta_termino_residencia.docx
- carta_aceptacion_servicio_social.docx

Cada archivo es una copia del machote original (con su membrete, logos y pie de página) a la que se le sustituyen
los datos variables por marcadores del tipo `${nombre_estudiante}`. No guardes aquí documentos con datos reales de estudiantes.
